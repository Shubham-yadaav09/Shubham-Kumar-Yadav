# Shubham Kumar Yadav — Portfolio Website

A responsive, single-page portfolio website designed for interviews, placements, and professional networking. It uses plain HTML, CSS, and JavaScript, so it can be hosted free with GitHub Pages.

## 1. Personalise before publishing

Open `index.html` and search for `ADD`, `YOUR`, and `replace this`.

Update these items:
- Email address
- LinkedIn URL
- GitHub username and URL
- Education years and expected MBA completion year
- Internship dates and the exact website/project name
- Project descriptions, your individual contribution, technologies, screenshots, GitHub/demo links
- Certification URLs and completion dates
- Any additional achievements, workshops, leadership roles, or relevant coursework

**Important:** The website includes only the facts currently confirmed. Draft project cards are placeholders; replace them with genuine work before sharing with recruiters. Do not claim a tool or skill unless you can explain and demonstrate it.

## 2. Preview locally

You can simply open `index.html` in a browser. No build tools or dependencies are required.

## 3. Publish with GitHub Pages

1. Sign in to GitHub and create a new **public** repository named `shubham-portfolio` (or another name you prefer).
2. Upload `index.html` and `README.md` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish. Your website URL will look like:
   `https://YOUR-GITHUB-USERNAME.github.io/shubham-portfolio/`
